# Space Invaders 2.0
CS-122 Course Project - Omar Adrianne Bapora, Ryder Sabale

Instructions: To run our code, simply run the "alien_invasion.py" file from the directory of this folder. Then, a window should pop up and the game can be played. 


**How to Play**
* Start the game by clicking the play button
* Controls
  * Movement - W,A,S,D
  * Firing - Enter/Return
* Rules
  * Clear the stages by shooting down all the aliens
  * Each time you clear a stage, the game speeds up
  * You have 3 lives
    * You lose a life if your ship touches an alien or if an alien reaches the bottom of the screen
  * Clear as many stages as you can before you run out of lives
